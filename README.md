# ▶ TakyLive

Подарки, лайки и чат TikTok Live управляют игрой: Minecraft, GTA 5, CS2, Rust, ARK, Palworld,
Project Zomboid, 7 Days to Die, Valheim и любая другая — через клавиатуру.

**Скачать:** раздел [Releases](../../releases/latest) → `TakyLive-Setup-….exe`.
Программа обновляется сама: значок версии в шапке → «Обновить».

Что умеет: шаблоны под каждую игру, озвучка чата (Microsoft, Google, Fish Audio) с защитой от мата и спама,
голоса зрителей, оверлеи для OBS, итоги эфира, пульт с телефона, анонсы в Telegram и Discord, битва команд,
колесо фортуны, очки зрителей, ИИ-соведущий, свои серверы Minecraft и Steam-игр с консолью.

## Подписка

Озвучка чата, заказ музыки, ИИ-соведущий, ИИ-голос и действия за подарки без ограничений — по подписке
на месяц. Ключ работает на двух компьютерах. Остальное (оверлеи, таймер, колесо, очки, команда и первые
12 карточек подарков) — бесплатно.

Ключ вставляется в программе: «⚙ Настройки → ⭐ Подписка». Купить или продлить — Telegram **@Takymi1**.
