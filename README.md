# ▶ TakyLive

Подарки, лайки и чат TikTok Live управляют игрой: Minecraft, GTA 5, CS2, Rust, ARK, Palworld,
Project Zomboid, 7 Days to Die, Valheim и любая другая — через клавиатуру.

**Скачать:** раздел [Releases](../../releases/latest) → `TakyLive-Setup-….exe`.
Программа обновляется сама: значок версии в шапке → «Обновить».

Что умеет: шаблоны под каждую игру, озвучка чата (Microsoft, Google, Fish Audio) с защитой от мата и спама,
голоса зрителей, оверлеи для OBS, свои серверы Minecraft и Steam-игр с консолью.

Подробная инструкция — [КАК_ЗАПУСТИТЬ.md](КАК_ЗАПУСТИТЬ.md).
