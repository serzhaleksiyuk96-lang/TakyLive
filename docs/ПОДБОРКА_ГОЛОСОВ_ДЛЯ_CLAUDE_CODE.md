# Задание для Claude Code: собрать «⭐ Рекомендуемые голоса» для TakyLive

В TakyLive 1.71 есть раздел «⭐ Рекомендуемые» в «🎮 Интерактив» → «🎙 ИИ-голос» → «Голоса».
Это список **ссылок** на модели RVC на Hugging Face — сами файлы каждый пользователь
скачивает себе сам одной кнопкой. Список лежит в файле `voice_presets.json` в корне
репозитория; программа берёт свежий с GitHub раз в час, поэтому новый релиз не нужен.

Твоя задача — найти и проверить 8–15 хороших голосов и заполнить этот файл.
Говори со стримером по-русски, просто.

## Какие голоса подходят (всё обязательно)

1. **Открытая лицензия, указанная в карточке модели**: MIT, Apache-2.0, CC0, CC-BY-4.0,
   OpenRAIL / CreativeML OpenRAIL-M. Нет лицензии или «non-commercial» / «personal use» —
   не берём (стрим может быть монетизирован).
2. **Не клон реального человека и не известный персонаж.** Пропускай всё, что названо
   по имени человека (блогеры, стримеры, артисты, политики, актёры озвучки) или персонажа
   игры / аниме / мультфильма / фильма — даже если лицензия открытая: автор модели
   не может разрешить чужой голос. Если описание молчит, на кого обучали, — тоже пропускай.
3. **Голос-«тип», а не человек**: робот, демон, монстр, низкий мужской, высокий женский,
   старик, ребёнок-мультяшка, диктор/рассказчик, инопланетянин, бурундук и т.п. Можно
   голоса, обученные на открытых датасетах с явным разрешением (например, на синтетике
   или на записях, которые автор сделал сам и разрешил).
4. **Звучит нормально**: без сильного шипения, понятно, держит русскую речь.
5. Размер `.pth` до ~200 МБ, `.index` до ~500 МБ.

## Как проверять

1. Тестовая копия TakyLive 1.71 (`git pull` в `TakyLive_test`), голосовая программа запущена
   (см. `docs/ГОЛОС_RVC_ДЛЯ_CLAUDE_CODE.md`).
2. Ищи на huggingface.co (браузер или «🔎 Библиотека голосов» в TakyLive): rvc + robot,
   demon, monster, deep, female, narrator, old, cartoon, alien…
3. Открой карточку модели: лицензия, описание, на чём обучена. Не подходит по правилам —
   дальше.
4. Поставь через «⬇ Поставить», нажми «▶ 10 с», попроси стримера сказать пару фраз.
   Запиши впечатление (1–5) и задержку из окна голосовой программы.
5. Удалять установленные голоса не обязательно — стример решит сам.

## Формат `voice_presets.json`

```json
{
 "about": "...оставь как есть...",
 "voices": [
  {"name": "Робот", "emoji": "🤖", "desc": "металлический, для подарков-приколов",
   "repo": "владелец/модель", "model": "путь/к/файлу.pth", "index": "путь/к/added_....index",
   "zip": "", "license": "mit", "size_mb": 60}
 ]
}
```

- `name` — короткое русское имя (оно же пойдёт в команду `voice:Робот:30`), без имён людей
  и персонажей.
- `model` и `index` — точные пути файлов внутри репозитория (как в «Files and versions»).
  Если голос лежит только в архиве — `"model": ""`, `"zip": "путь/к/архиву.zip"`.
- `license` — как в карточке модели. `size_mb` — примерный общий размер.

## Отчёт

Создай `ОТЧЁТ_ПОДБОРКА_ГОЛОСОВ.md`: таблица — имя, ссылка на модель, лицензия, на чём
обучена (со слов автора), оценка звука, задержка; и отдельно — какие модели отбросил и почему
(коротко). Заполненный `voice_presets.json` и отчёт стример перешлёт в чат, где делается
TakyLive; там его добавят в репозиторий. Сам ничего не пушь.
